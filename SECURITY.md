# Security policy

Please report security issues privately through GitHub Security Advisories.
Do not open a public issue for a suspected vulnerability.

Supported security fixes target the current stable release and, before 1.0,
the newest preview release. Reports should include affected version, impact and
minimal reproduction steps without private user data.

YF Toolbox processes files locally and has no telemetry. Release credentials,
signing identities and ImageSharp license keys must only exist in the protected
`release` environment and must never be committed.
